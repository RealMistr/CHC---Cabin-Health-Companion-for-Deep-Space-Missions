    Bio-Monitor

    All values in this section are measured by the Bio-Monitor, a sensor shirt and headband the astronaut wears all the time. Each value is the median of the last few minutes. Select one for details.

    Trends

    Prototype built for a hackathon. The normal ranges are general adult reference values and assumptions, not NASA flight limits, and nothing here is a diagnosis. Act now steps are written for the crew to carry out on board; the Crew Medical Officer, the crewmate trained for medical care, decides on treatment. Personal limits should be agreed with the medical team before the mission. All times are UTC, the mission's time.

    Data

    Load JSON files from the team. You can load several at once (for example one with Bio-Monitor data and one with checks); they are merged. The first upload replaces the sample data. Everything stays in this browser.

    Each crew member's data is kept apart by the name in the file ("crew": {"name": "Aleš Svoboda"}); files without a name go to the crew member on screen. Old dates are moved forward so the data ends today, and only the last 30 days are kept. Radiation is shown in gray (µGy/h, mGy). Older files in sievert (µSv/h, mSv) are converted to gray.

    Paste JSON instead

    File format: see DATA.md in the project folder.
